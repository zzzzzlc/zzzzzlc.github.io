# 玄幻修仙 AI 动态漫自动化 SOP

## 目标与边界

从零运营抖音账号，以 35–55 秒竖屏玄幻修仙动态漫实现快速验证增长和后续广告/带货变现。每天人工投入控制在 1–2 小时；先日更 1 条。自动化承担生产和数据整理，人保留选题、终审、发布和互动的决定权。

本方案的发布边界是“生成发布包 + 人工确认发布”。不在起号期部署无人审核的自动发帖或批量刷量。

## 内容策略

- 主赛道：玄幻修仙连续短剧。
- 单条结构：0–3 秒危机钩子；3–12 秒交代目标；12–28 秒压迫升级；28–42 秒身份/修为/法器反转；42–52 秒新威胁；结尾给出二选一评论钩子。
- 时长与画面：35–55 秒，9:16，12–18 个镜头。每条用 6–8 张关键帧配合推拉、景深、粒子、法术效果和转场，避免逐镜头高成本视频生成。
- 连载原则：每条拥有唯一编号 `XJ-001`；结尾必须把下一集冲突说清楚。

## 内容资产

建立一个内容中控表，至少包含以下数据表：

| 表 | 关键字段 | 用途 |
|---|---|---|
| 内容圣经 | 角色、脸部/服饰、法器、境界、世界规则、画风提示词、禁用元素 | 所有生成任务的唯一事实来源 |
| 选题池 | 编号、标题、冲突、反转、评论钩子、系列、评分、状态 | 每周从 30 个候选中选择日更内容 |
| 生产单 | 选题编号、脚本、分镜、提示词、配音文本、素材链接、审核状态 | 驱动单集生成和返工 |
| 发布记录 | 成片、封面、标题、话题、置顶评论、发布时间、平台链接 | 保留可复用发布包 |
| 数据复盘 | 播放、首屏/前段留存、完播、点赞、评论、转发、涨粉、转化 | 排序下一周的选题与钩子 |

文件目录以编号存放：`assets/XJ-001/{script,storyboard,frames,audio,project,final,cover}`。不可把临时生成文件混入最终成片目录。

## 工作流

1. 每周触发一次“选题批次”：模型基于内容圣经输出 30 个候选；每个候选都包含冲突、反转、标题、结尾评论题和评分理由。
2. 每天由创作者在中控表选择一条，状态改为“已确认”。
3. 自动化生成脚本、8–12 格分镜、逐格提示词、旁白、台词、字幕、封面文案、标题、话题和置顶评论草稿，状态改为“待生成素材”。
4. 画面服务按角色参考图生成关键帧和少量图生视频镜头；配音服务生成旁白和带时间戳的字幕。自动剪辑模板合成预览成片，状态改为“待机器质检”。
5. 机器质检通过后状态改为“待人工审核”，失败则写入具体失败项并退回相应步骤。
6. 创作者只审核画面连续性、剧情、钩子、字幕、声音和合规；通过后状态改为“待发布”。
7. 自动化输出发布包；创作者在抖音人工发布、声明 AI 生成内容、填写最终话题并置顶评论。发布后状态改为“已发布”。
8. 次日录入或在获得授权后同步数据；系统更新选题评分。周末输出复盘报告。

## 人机分工与工具

| 环节 | 默认工具类别 | 责任人 |
|---|---|---|
| 状态/素材中控 | 飞书多维表格或 Notion | 自动化维护；创作者决策 |
| 编排 | n8n 或同类工作流工具 | 自动化 |
| 脚本/质检 | 一个固定主模型与结构化提示词 | 自动化初稿；人工终审 |
| 画面/图生视频 | 支持角色参考的生成平台 | 自动化批量生成 |
| 旁白 | API TTS 服务 | 自动化 |
| 最终剪辑 | 固定动态漫模板 | 自动化合成；人工微调 |
| 发布和互动 | 平台原生发布器 | 创作者 |

月度试跑预算为 800–1,500 元：脚本模型 100–300 元、画面/视频积分 500–900 元、配音与自动化 100–300 元。连续两周单条素材成本超过预算上限时，先减少图生视频镜头数量，而不是削减角色一致性素材。

## 质检与返工

机器初检必须检查：

- 成片为 9:16，时长 35–55 秒，音视频轨、封面、字幕和标题完整；
- 首句在第 1 秒内出现；
- 字幕不溢出安全区域、无空白段、无明显错字；
- 角色参考、场景和法器素材齐全；
- 标题、封面、话题不与近期内容重复；
- 敏感表达、未授权 IP、真人肖像/声音和明显侵权风险被标记。

返工只返回失效步骤：角色不一致时重绘对应帧；字幕错误时重生成字幕；前 3 秒无钩子时重写开头和封面；不因局部问题重做整集。

人工终审清单：主角是否一致、故事是否不用看前集也能读懂、前三秒是否有冲突、反转是否兑现、字幕是否易读、音乐不盖过旁白、是否含 AI 内容声明和不当素材。

## 日程与复盘

- 每日：10 分钟确认选题；25–40 分钟审核成片；25–40 分钟发布与互动。
- 每周：批量生成选题；预留 3 条已审核库存；周末用 90 分钟比较表现最好的 3 条与最差的 3 条。
- 首个 30 天：只验证题材、钩子和封面组合，日更 1 条，不强行硬广。
- 第 31–60 天：保留表现最好的 2 个系列，测试小说、听书、壁纸或提示词包等与剧情自然相关的低打扰转化。
- 后续：在内容稳定后测试软广、定制动态漫、IP 会员内容和联盟带货。

复盘优先级：首屏/前段留存、完播、评论率、涨粉、转化。播放量只作为辅助指标。每周只改变一个变量：钩子、封面、题材或结尾互动中的一项。

## 合规与发布

- 使用原创角色、原创世界观和有商业使用权的音画素材；不模仿现有动漫 IP，不使用公众人物脸部/声线或未授权素材。
- 每次发布主动声明为 AI 生成/制作内容，并使用平台提供的标识能力；保留生成来源、提示词和导出文件记录。
- 不删除、规避或篡改生成内容标识。
- 发布采用人工确认。若未来接入抖音开放平台发布能力，必须先完成应用申请、用户授权、权限审核和端到端测试。

## 首周启动清单

1. 注册账号，完成头像、昵称、简介和“原创 AI 修仙动态漫”定位。
2. 写完内容圣经：至少 2 位主角、1 位反派、3 个场景、3 个境界、2 件法器。
3. 生成并人工挑选角色参考图，锁定色板、镜头语言、字幕样式、旁白声线和封面版式。
4. 建好中控表、文件目录和四个状态：待审核、待发布、已发布、需返工。
5. 先做 3 条不发布的样片，验证角色一致性、字幕安全区和模板节奏。
6. 用最好的样片发布第 1 条；再开始日更。第 7 天完成第一次复盘并保留 3 条库存。

## 验收标准

首周结束时，应能从一个“已确认”的选题自动得到完整生产包，并在人工终审后获得可发布的成片和文案。创作者每日人工时间不超过 2 小时，且可追溯每条内容的素材、版本、发布信息和复盘数据。
