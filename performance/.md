* TypeScript

## Lighthouse 当前问题

### 1、Critical Request Chains

当前关键请求链：

```
HTML
│
├── index.js (243KB)
│      │
│      ├── three.module.js (139KB)
│      │
│      ├── index.css
│      │
│      ├── AuthorBio.js
│      │      └── AuthorBio.css
│      │
│      └── 其它首页业务代码
│
└── JetBrains Mono (CDN)
```

Critical Path Latency：

```
1368 ms
```

---

### 2、Render Blocking Resources

外部字体：

```
JetBrains Mono
400.css
500.css
600.css
```

来源：

```
cdn.jsdelivr.net
```

导致：

* 首屏阻塞约 200\~400ms
* 新建 CDN 连接
* 字体 CSS 进入关键路径

---

### 3、Unused JavaScript

主要来自：

* Ant Design
* Three 业务代码
* 其它首页模块

播放器项目：

```
hls.js
dash.js
```

属于另一个项目。

# 三、优化方案

---

# 第一阶段（最高优先级）

## 1. 保留 Three.js 首屏加载

首页就是 Three.js 场景，因此：

**Three.js 不做懒加载。**

原因：

* Three.js 是首页核心内容
* 延迟加载会造成首屏闪烁
* 用户体验下降

因此：

```
three.module.js
```

继续保留在首屏。

优化重点放在：

> Three.js 之外的业务代码。

---

## 2. 精简首页入口 JS

当前：

```
index.js
243KB
```

检查：

是否存在：

```
Markdown
Blog
Author
Code Highlight
Analytics
Search
Comment
Admin
```

如果不是首页必须：

全部拆分。

React：

```tsx
const AuthorBio = lazy(() => import("./AuthorBio"));
```

不要：

```tsx
import AuthorBio from "./AuthorBio";
```

---

## 3. AuthorBio 延迟加载

当前：

```
index
↓

AuthorBio

↓

AuthorBio.css
```

建议：

滚动到底部后：

```
IntersectionObserver

↓

加载 AuthorBio
```

收益：

减少首页关键请求。

---

# 第二阶段

## 4. 本地托管字体

不要：

```
cdn.jsdelivr.net
```

改成：

```
public/fonts/
```

CSS：

```css
@font-face {
    font-family: "JetBrains Mono";
    src: url("/fonts/JetBrainsMono-Regular.woff2") format("woff2");
    font-display: swap;
}
```

收益：

* 少一次 CDN 连接
* 减少阻塞
* 浏览器缓存更稳定

---

## 5. 只加载需要的字重

目前：

```
400
500
600
```

如果页面没有使用：

```
500
600
```

删除：

```
500.css

600.css
```

保留：

```
400.css
```

---

# 第三阶段

## 6. Three.js 业务代码拆分

虽然 Three.js 保留首屏加载，

但是：

```
Loader

EffectComposer

Bloom

HDR

GLTFLoader

OrbitControls
```

可以按需加载。

例如：

```ts
const { GLTFLoader } = await import(
    "three/examples/jsm/loaders/GLTFLoader"
);
```

不要首页同步：

```
HDR

Bloom

Outline

DRACO
```

---

## 7. 模型异步加载

推荐：

```
Scene

↓

Renderer

↓

Camera

↓

第一帧

↓

开始下载模型
```

而不是：

```
模型下载完成

↓

开始渲染
```

收益：

首屏更快出现。

---

## 8. 贴图异步加载

例如：

```
HDR

4K Texture

Normal Map

AO Map
```

全部：

```
TextureLoader.load()
```

异步下载。

# 第四阶段

## 9. React Route 懒加载

首页：

```
Home
```

其它页面：

```
Blog

Archive

About

Tags

Projects
```

全部：

```tsx
lazy(() => import(...))
```

不要：

```
首页加载所有页面。
```

---

## 10. Ant Design

检查：

是否：

```ts
import * as antd from "antd";
```

或者：

```ts
export * from "antd";
```

改成：

```ts
import {
    Button,
    Card,
    Typography
} from "antd";
```

避免：

整个 antd 进入首页。

---

## 11. Ant Design Icons

避免：

```ts
import * as Icons from "@ant-design/icons";
```

改成：

```ts
import {
    HomeOutlined,
    GithubOutlined
} from "@ant-design/icons";
```

---

# 第五阶段

## 12. Vite Chunk 拆分

建议：

```ts
manualChunks(id) {

    if (id.includes("three")) {

        return "three";

    }

    if (id.includes("antd")) {

        return "antd";

    }

    if (id.includes("node_modules")) {

        return "vendor";

    }

}
```

收益：

浏览器缓存更稳定。

---

## 13. Build Target

建议：

```ts
build: {

    target: "es2022",

    cssCodeSplit: true,

    modulePreload: true

}
```

避免：

转译过多旧浏览器代码。

# 七、播放器项目（附录）

播放器项目存在：

```
hls.js

dash.js
```

目前：

```
首页同时下载：

dash.js

hls.js
```

建议：

```ts
await import("hls.js");
```

以及：

```ts
await import("dashjs");
```

按播放协议动态加载。

收益：

减少约：

```
2MB+
```

首页 JS。
